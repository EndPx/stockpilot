## Orbital-S logo and icons — 2026-09-23

Created using the built-in imagegen tool, then refined once with that tool. The first
draft was rejected for background artifacts. No external brand reference was used.
The selected opaque 1254 × 1254 master is preserved unchanged in
`apps/web/public/brand/stockpilot-logo-master.png`. This is raster generated artwork,
not a manually traced or invented SVG. The StockPilot wordmark remains HTML text.

Deterministic resize/encoding only: `node apps/web/scripts/export-brand-assets.mjs`
uses Next's existing Sharp dependency. Outputs:

- `apps/web/public/brand/stockpilot-mark.png`: 128px shared header/footer/auth mark.
- `apps/web/app/favicon.ico`: 16, 32 and 48px frames.
- `apps/web/app/icon.png`: 48px browser icon.
- `apps/web/app/apple-icon.png`: 180px Apple touch icon.
- `apps/web/public/brand/icon-192.png` and `icon-512.png`: manifest icons.

The manifest uses browser display mode; it does not add a service worker, offline
financial caching, or an installability claim. All icons use the same unchanged
mark, with small-size antialiasing from the image encoder.
